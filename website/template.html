How the numbers work

Stats you can trust

Lock-in writes its rules down, so a chart never quietly changes meaning.

Estimated one-rep max

e1RM = weight × (1 + reps ÷ 30)

The Epley formula, only for sets of 1 to 12 reps. Beyond that the estimate stops meaning much, so it isn't shown.

Training volume

volume = Σ weight × reps

Counted over completed working sets. Warm-ups never count toward volume or records.

Units never rewrite history

stored: kg · cm · %

Switch between kg and lb any time. Only the display changes; your logged sets stay exactly as recorded.

History survives edits

exercise_name_snapshot

Rename or archive an exercise and past workouts keep the name they were logged with. Nothing is hard-deleted.

Web app

Same app, in your browser

Lock-in's web version is built from the same code as the Android app.

  • Stored in your browser. SQLite runs inside the page, so your data never goes to a server.
  • Phone layout on any screen. On a desktop it stays a tidy centred column.
  • Move data with backup files between phone and web, once backup lands in v0.7.
